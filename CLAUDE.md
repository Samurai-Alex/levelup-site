# levelup-tracker.com — сайт LEVEL UP

## Правила работы
- Отвечать пользователю **по-русски**.
- Неясно — сначала уточнить. **Любое изменение на сайте:** сначала рассуждать как опытный дизайнер-разработчик сайтов (что продаёт, что мешает скачиванию, телефон, SEO), честно сказать своё мнение, затем **2–3 варианта** с рекомендацией; делать после выбора.
- Тексты сайта — на трёх языках: украинский, русский, английский.
- Стиль: тёмный фон, зелёный акцент как в программе (#1fd65f), пиксельный заголовок (Press Start 2P), основной шрифт JetBrains Mono. Без эмодзи в интерфейсе.
- В подвале всегда ссылки на документы. Фраза «Информация на сайте не является публичной офертой» — только в «Условиях использования» (`terms.html`), из подвала убрана по просьбе владельца.
- LEVEL UP станет платной: место под цены и кнопку покупки — объект `SHOP` в `index.html` (`buy: true`, ссылка, цена).
- Не коммитить секреты. Владелец в документах — просто «LEVEL UP», почта — support@levelup-tracker.com.

## Стек
- Статический сайт без сборки на **GitHub Pages** (репозиторий `Samurai-Alex/levelup-site`, ветка `main`), Jekyll по умолчанию (`_config.yml` скрывает `CLAUDE.md`, `README.md`, `tools/`).
- Домен в **Cloudflare** (записи DNS only), подтверждён в GitHub, HTTPS включён (Let's Encrypt от GitHub).
- Почта support@levelup-tracker.com — Cloudflare Email Routing → Gmail пользователя.

## Файлы
- `index.html` — главная и русская версия (`/`); тексты в JS-объекте `L` (uk/ru/en, плюс `mT`/`mD`/`oT`/`oD` — title, description, соцсети). `uk/index.html` и `en/index.html` — копии с текстами своего языка, руками не править: их, тексты в HTML, hreflang и `sitemap.xml` собирает `node tools/pages.mjs`. Пути в странице — от корня (`/img/…`). Первый визит на `/` — по языку браузера, выбор в переключателе запоминается (`localStorage.lang`).
- `about.html`, `terms.html`, `privacy.html`, `contact.html` — документы; общие `docs.css` и `docs.js` (шапка, подвал, язык).
- `img/<язык>/` (ru, uk, en) — снимки программы на демо-данных в валюте языка: `home` (первый экран), `game.mp4`/`game.jpg` (LVL 1, «Закрытый день»), `lvl2`–`lvl4` (разделы LVL), `themes.mp4`/`themes.jpg` (LVL 5: темы по очереди на живом фоне «Level Up», стеклянные карточки, кнопки тем подсвечиваются по времени видео); `img/og.png`, `img/alex.png`. `changes.js` — «Что нового».
- Главная: первый экран с блоком «Кто делает», пять разделов LVL (квест-карточка + снимок в зелёной рамке), «А ещё», установка, цены, «Что нового», вопросы, финальный призыв.
- `bg.js` — живой фон «Level Up» как в программе (тихий: меньше и бледнее, без волн; пауза в скрытой вкладке, нет при выключенных анимациях); карточки главной — «стекло» поверх него.
- `CNAME`, `robots.txt`, `sitemap.xml`.

## Команды
- Переснять скриншоты и видео: `node tools/capture.mjs` (Chrome headless, берёт программу из `../HabitTrackerApp/app`; для видео тем нужен системный ffmpeg — `winget install Gyan.FFmpeg`). После съёмки **каждый снимок проверять глазами дизайнера-перфекциониста**: ровные колонки виджетов, видны оба состояния (отмечено / не отмечено), нет обрезанного текста, чужого языка или валюты, всплывающих окон, «минусов» в деньгах; нашёл — поправить демо в скрипте и переснять.
- **После любой правки `index.html`:** `node tools/pages.mjs` (иначе /uk/ и /en/ отстанут).
- Счётчик скачиваний и воронка (dl.levelup-tracker.com, `tools/counter`): после правки `worker.js` — `node tools/counter/setup.mjs` (запускает владелец: читает токен бота из `%USERPROFILE%.taurieedback.json`), тесты — `node --test tools/counter`. Отчёт в Telegram по понедельникам. Ссылки, которые публикуешь, — с меткой `?s=tg`, `?s=yt` и т.п.
- «Что нового» после релиза программы: `node tools/changes.mjs`.
- Картинка для соцсетей: команда в шапке `tools/og.html`.
- Локальный просмотр: сервер этой папки на `http://localhost:8776/`.
- Публикация: коммит, затем
  `git -c credential.helper= -c "credential.helper=!'C:/Program Files/GitHub CLI/gh.exe' auth git-credential" push origin main`
  (обычный `git push` зависает на окне входа). Сайт обновляется примерно за минуту.
- Если push отклонён: GitHub сам добавляет коммиты с `CNAME` при смене домена — `git fetch`, затем `git rebase origin/main`.
