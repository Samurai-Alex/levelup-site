# Подборки трекеров привычек — куда писать

Цель: попасть в статьи-подборки, которые уже стоят высоко в Google. Одна такая ссылка
весит больше месяца работы над сайтом. Письма отправляются с support@levelup-tracker.com.
Ссылки в письмах — с меткой `?s=pr`, чтобы счётчик показал переходы.

подставить имя в письмо. Писать одно письмо — один адрес, без массовой рассылки.
