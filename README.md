# LEVEL UP — сайт продукту

Статична сторінка для GitHub Pages (levelup-tracker.com). Скриншоти — демо-дані програми.
Після беты: у index.html увімкнути SHOP.buy і вказати посилання на оплату.
Коли домен підключено до DNS — додати файл CNAME з levelup-tracker.com.

## Оновлення матеріалів
- `node tools/capture.mjs` — нові скриншоти (6 сторінок, 6 тем) і відео `img/demo.mp4` з програми на демо-даних.
- `node tools/changes.mjs` — блок «Що нового» з `HabitTrackerApp/app/js/updates.js` (після кожного релізу).
- Картинка-превью для соцмереж — команда в шапці `tools/og.html`.
